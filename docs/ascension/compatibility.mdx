# Compatibility

DiscordSRV requires Java 21 or newer

## Server Software compatibility

| Server software    | Supported versions                                                                |
|--------------------|-----------------------------------------------------------------------------------|
| [Paper] and forks  | ✅ Minecraft 26.2 (Paper build)<br/> ⚠️ Minecraft 1.7.10-26.1.2 (Bukkit build)[^1]  |
| [Bukkit], [Spigot] | ⚠️ Minecraft 1.7.10-26.1.2[^1]                                                     |
| [Fabric]           | ✅ Minecraft 1.19 and above                                                        |
| [NeoForge]         | ✅ Minecraft 1.21.1 and above                                                      |
| [BungeeCord][^2]   | ✅ Latest build                                                                    |
| [Velocity][^2]     | ✅ 3.4.0+                                                                          |

[^1]: We recommend using Paper using the latest Minecraft version. Spigot, Bukkit and old versions of Minecraft don't support all features.
[^2]: Proxy support is limited

**Compatibility notes**

| Status | Plugin | Explanation |
|--:|-----------------------------------|---------------------------------------------------------------------|
| ✅ | [FactionsUUID]                    | Requires `1.6.9.5-U0.3.0b133` and up for global chat to be forwarded |
| ❌ | [SARanks (TModsServerAddons_Ranks)] | Cancels all chat events |
| ❌ | [EpicChatFormat (EpicChatPrefix)] | Cancels all chat events |
| ✅ | [FreedomChat]                     | Works at packet level |
| ⚠️ | [AntiPopup]                      | Cancels all chat events, unless `clickable-urls` is disabled |
| ❌ | [NoChatReports]                   | Cancels all chat events |
